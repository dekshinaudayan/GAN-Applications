# GAN Assignment

## Overview

This repository contains the implementation of Generative Adversarial Networks (GANs) developed for the Machine Learning and Neural Networks assignment.

### Contents

- Part 1 – GAN from Scratch
- Part 2.1 – OCTMNIST Retinal Image Generation
- Part 2.2 – CICIDS2017 Synthetic Network Traffic
- Part 2.3 – QuickDraw Birthday Cake Sketch Generation

## Requirements

Python 3.10+

Required libraries:

- torch
- torchvision
- numpy
- pandas
- matplotlib
- scikit-learn
- medmnist
- torchmetrics
- torch-fidelity

## Running the notebook

Open the notebook in Google Colab or Jupyter Notebook and run all cells from top to bottom.

The notebook automatically downloads the required datasets during execution.
